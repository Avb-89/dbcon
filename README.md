# dbcon

dbcon — консольная утилита для работы с SQLite. Работает как инструмент командной строки, интерактивная оболочка и локальный MCP-сервер для ИИ-ассистентов.

# Установка на macOS

Скачай исполняемый файл `dbcon` из раздела [Releases](https://github.com/Avb-89/dbcon/releases). В терминале перейдите в папку с загруженным файлом и выполни:

```sh
mkdir -p "$HOME/.local/bin" && mv ./dbcon "$HOME/.local/bin/dbcon" && chmod +x "$HOME/.local/bin/dbcon"
```

Для стандартной оболочки macOS — zsh — добавь каталог в `PATH`:

```sh
echo 'export PATH="$HOME/.local/bin:$PATH"' >> "$HOME/.zshrc" && source "$HOME/.zshrc"
```

# Что умеет

### Показывать структуру базы

Показывает таблицы, их столбцы, типы данных и ограничения.

### Читать и искать записи

Позволяет выбирать нужные поля, фильтровать и сортировать записи. Поддерживает простой поиск и поиск по сочетанию признаков, в том числе в соседних записях одной группы.

Вместо большой выгрузки можно получить короткие выдержки, а затем прочитать нужные оригиналы и их окружение.

### Работать с JSON внутри SQLite

Умеет читать и искать отдельные значения внутри JSON, включая текст в элементах массивов.

### Считать, не выгружая содержимое

Считает все записи, подходящие под условия или содержащие непустые значения — без выгрузки самих данных.

### Изменять данные

Добавляет, обновляет и удаляет записи. По умолчанию база открывается только для чтения; запись нужно разрешить явно.

### Работать на SQL

В интерактивной оболочке можно выполнять SQL напрямую, работать с транзакциями и использовать средства администрирования SQLite.

## Три способа работы

### 1. Команда в терминале

Один запуск выполняет действие и завершает работу. Подходит для быстрых проверок и скриптов.

Например, посмотреть таблицы существующей базы:

```sh
dbcon --db ./work.db --tables
```

Данные можно смотреть целиком или в компактной таблице.

### 2. Интерактивная оболочка

Позволяет работать с базой последовательно, не открывая подключение для каждой команды. Можно чередовать SQL и команды с флагами, сохранять изменения или отменять их. При выходе несохранённые изменения откатываются.

### 3. MCP для ИИ-ассистента

Даёт ассистенту инструменты для изучения базы, поиска, чтения и подсчёта записей. При разрешённой записи доступны добавление, обновление, удаление и пакетные операции.

Ассистент может сначала получить короткие поисковые выдержки, затем прочитать нужные оригиналы и соседние записи — без загрузки всей переписки или таблицы в контекст.

MCP использует тот же поиск, что терминал и оболочка. Работает локально, без отдельного сетевого сервера. Настройка подключения описана во встроенном руководстве.

## Подключение и безопасность

Открывает существующую базу SQLite. Подключение можно указать при запуске или сохранить через интерактивный мастер.

По умолчанию доступно только чтение; для изменений нужен `-w`. При запуске MCP режим задаётся явно: `--mcp -r` для чтения или `--mcp -w` для чтения и записи.


## Где смотреть подробности

Все команды, параметры, ограничения и примеры подключения — во встроенном руководстве на русском и английском:

```sh
dbcon --help
dbcon --man ru
dbcon --man en
```
